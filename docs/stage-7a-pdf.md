# Stage 7A — PDF report

Stage 6 is accepted with production prompt `RU-1.2` and schema `RU-1.0`. Stage 7A adds a server-side, version-pinned PDF download for completed diagnostics. The document is rendered from the immutable company snapshot, deterministic result, pinned block translations/results, and the selected completed AI report; it does not invoke OpenAI or scoring.

PDF rendering uses the existing Playwright Chromium dependency and A4 HTML/CSS with system fonts for Cyrillic support. Generated artifacts are persisted in `report_artifacts` with a unique `(report_id, format, template_version)` key and a foreign key to `(ai_report.id, ai_report.version)`. The current local Supabase instance has no Storage schema, so Stage 7A stores the generated bytes in the private server-side artifact table; the authorized route is the only download path. This can be migrated to private Storage later without changing report-version semantics.

Stage 7A is complete for PDF only. Email delivery, consultation, feedback, and the Admin UI remain outside this stage. Official logo and final pagination acceptance remain open decisions.
