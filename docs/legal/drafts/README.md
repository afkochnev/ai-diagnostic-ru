# Следующий privacy/consent пакет — проекты для рассмотрения

Эти тексты **не утверждены и не опубликованы**. Их наличие в репозитории не
активирует новые согласия и не изменяет документы в staging или production.

- [Политика обработки данных](data-processing-policy-ru-v1.md).
- [Отдельное согласие на обработку данных](data-processing-consent-ru-v1.md).
- [Отдельное маркетинговое согласие](marketing-consent-ru-v1.md).

Источники решений: [принятый инфраструктурный риск](../../v27-owner-risk-decisions.json),
[модель хранения](../../v27-retention-model.json) и утверждённая
[коммерческая оферта](../advanced-terms-ru-v1.md).
Статусы и будущие соответствия версий заданы в [манифесте пакета](../../v27-legal-package.json).

`OWNER_ACCEPTED_RU_DATA_LOCALIZATION_RISK` не блокирует V2.7. Это решение
владельца о риске текущей архитектуры, а не подтверждение полного юридического
соответствия. В проектах раскрыты Supabase, Render, OpenAI, Resend и YooKassa,
передаваемые категории данных и возможная обработка вне РФ. Обещания физического
хранения всех данных в России нет.

Перед переводом текстов в approved-состояние необходимо рассмотреть точный текст,
фактические договорные условия поставщиков, обработку запросов на удаление/отзыв,
очистку по срокам и исключения для audit/legal/учётных записей. Дата вступления
в силу не назначена. Утверждение retention model не заменяет проверку её исполнения.

Технически сейчас подтверждено истечение доступа к anonymous session через 7 дней.
Физическое удаление по истечении срока, очистка analytics/email logs через 12 месяцев
и полный процесс удаления/анонимизации аккаунта этим изменением не реализованы.
Новые migrations, cleanup jobs или публикация legal documents не создавались.

После будущего утверждения: новые версии применяются только к новым согласиям
и соответствующим новым сценариям. Нельзя обновлять исторические
`user_consents` или `anonymous_diagnostic_consents`, менять их версии/время
задним числом или считать отказ от маркетинга согласием. Для соответствующего
нового действия незавершённой anonymous session используется явное повторное
согласие с добавлением новой записи, сохраняя старую историю. Массовой миграции
согласий существующих пользователей нет.

Проверенные источники по поставщикам:

- [OpenAI API data controls](https://developers.openai.com/api/docs/guides/your-data):
  `store:false` в коде не доказывает Zero Data Retention; у провайдера могут
  сохраняться журналы безопасности. Настройки конкретной API-организации не проверялись.
- [Supabase privacy](https://supabase.com/privacy): клиентские данные приложения
  обрабатываются в рамках соответствующего соглашения обработки данных.
- [Resend DPA](https://resend.com/legal/dpa): доставка включает обработку содержимого
  электронных сообщений. В данном приложении возможна отправка PDF-вложения.

Это проекты для утверждения владельцем, без production-изменений и без заявления,
что принятие риска заменяет применимые требования.
